# Project rules for Claude

## Never load tcrf.net

Do not fetch, search, or otherwise load any page on tcrf.net (The Cutting Room Floor),
including subdomains, mirrors, or cached copies. This applies even when the user pastes
a tcrf.net link directly. The user has been banned from the site for using Claude; any
request from Claude risks making that worse.

If a tcrf.net link comes up, say you cannot open it and ask the user to paste the
relevant content instead.
